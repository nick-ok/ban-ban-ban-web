# тип Message

## Структура сообщения

**Message** содержит:

- `id` — уникальный идентификатор (для работы с пулом и отслеживания)
- `user` — тип пользователя: `'male' | 'female' | 'anonymous' | 'bot'`
- `content` — контент сообщения:
  - `type` — тип контента: `'normal' | 'blurred' | 'ad' | 'caps' | 'fwords'`
  - `text` — текст сообщения (рандомно из соответствующего массива)
  - `likes` — количество лайков (рандомное число)
- `title` — тип заголовка: `'empty' | 'hype' | 'dissent'`
- `side` — сторона появления: `'left' | 'right'` (рандомно)
- `speed` — скорость движения (рандомно в заданном диапазоне)
- `banAction` — требуемое действие от игрока: `'ban' | 'longBan' | 'none'`

## Логика создания

1. **Назначение `banAction`** — согласно вероятностям сценария (например, 30/20/50)
2. **Генерация структурных параметров** — строго под назначенный `banAction`:
   - `'ban'` → параметры из `banPattern`
   - `'longBan'` → параметры из `longBanPattern`
   - `'none'` → параметры, не подходящие ни под один паттерн
3. **Рандомное наполнение** — текст, лайки, сторона, скорость
4. **Приоритет** — если параметры подходят под оба паттерна, применяется `'longBan'`

## Использование в игре

- При тапе по сообщению проверяется: совпадает ли действие игрока с `banAction`
- Сообщения с `'none'` должны быть пропущены (не банить)
- Статистика ведётся по каждому типу: правильно/неправильно/пропущено◊
